**Target utama:**

1. Integrasikan PostgreSQL 17 menggunakan pgx dan sqlc, dengan connection pooling, context timeout, graceful shutdown, serta migration SQL versioned. Jangan menjalankan migrasi pada database produksi.
2. Buat tabel provider_accounts, credentials, balance_snapshots, collector_runs, users, admin_sessions, dan audit_logs. Gunakan constraints, foreign keys, dan indeks yang sesuai.
3. Implementasikan credential vault AES-256-GCM dengan nonce acak, versioned ciphertext, dan master key dari .env. Master key tidak boleh disimpan di database.
4. Implementasikan autentikasi admin berbasis secure HTTP-only cookie session. Password menggunakan Argon2id. Simpan hanya hash token sesi. Terapkan CSRF protection, rate limiting login, dan secure cookie sesuai mode HTTPS. Jangan gunakan query-token authentication.
5. Implementasikan penyimpanan hasil collector ke PostgreSQL dengan transaksi dan idempotency. Jika collector gagal, jangan menimpa saldo terakhir dengan nol.
6. Pisahkan balance snapshots dari earnings terverifikasi. Jangan menghitung total earnings dari penjumlahan saldo.
7. Pertahankan seluruh tampilan dashboard dalam Bahasa Indonesia.
8. Rapikan .env.example, .gitignore, compose.yaml, README.md dan dokumentasi security.
9. Tambahkan unit tests serta integration tests PostgreSQL yang dapat dijalankan secara eksplisit. Jangan membuat test bergantung pada API provider live.
10. Gunakan fail-closed configuration untuk mode produksi. Jangan tampilkan credential atau informasi sensitif di response API/log.
